# 📊 Customer Churn Analysis Dashboard

## Project Overview
Analysis of Telco customer churn data to identify
why customers leave and how to retain them.

## Key Insights
- Overall Churn Rate: ~26%
- Month-to-month contracts churn most
- New customers (0-12 months) leave faster
- High monthly charges increase churn risk

## Tools Used
- Power BI
- DAX Measures
- Dataset: Telco Customer Churn (Kaggle)

## Dashboard Features
- KPI Cards (Total, Churned, Active, Churn Rate%)
- Churn by Contract Type
- Churn by Internet Service
- Churn by Tenure
- Interactive Slicers

## Dataset Link
https://www.kaggle.com/datasets/blastchar/telco-customer-churn
